# Release notes

## 3.4 — 2026-11-15

- Navidrome and Plex album browsing, search, playback and playlist saving in AudioWave. Connections use native desktop authentication and media handling.
- Google sign-in in AudioWave uses the system browser and desktop OAuth.
- Mini Player offers saved playlists and a visible always-on-top toggle; desktop Mini opens full-height at the right edge of the screen.
- Full-height desktop sidebar and clearer Queue, Shuffle all and Clear buttons.
- Surprise artist selection respects the selected genre.
- The in-app Install button is hidden; browser installation remains available through the browser menu.
