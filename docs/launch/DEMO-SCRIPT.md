# ArtistWave private demo script

**Target length:** 35–45 seconds · **Format:** screen recording with burned-in captions · **Audience:** private feedback group

## Capture checklist

- Use a clean guest browser profile. Keep account, API key, private files, and personal data off screen.
- Use one artist and recording whose source and rights have been checked.
- Keep browser chrome and unrelated notifications out of frame.
- Record at a readable desktop size; make a separate phone capture only if time allows.

## Shot list and captions

| Time | Screen action | Caption |
|---|---|---|
| 0–4s | Show the ArtistWave home screen and genre list. | Find your sound. |
| 4–12s | Search an artist with multiple matches and select the intended identity. | Choose the artist you mean. |
| 12–20s | Start an available recording and show its source label. | Preview recordings when a supported source has them. |
| 20–29s | Save the track to a playlist and open My Playlists. | Keep the tracks you want to return to. |
| 29–38s | Open the Mini Player and show its controls. | Take your listening with you. |
| 38–43s | End on the ArtistWave name and project URL. | ArtistWave · Find your sound. |

## Final review

- Captions match the actions and remain readable on a phone.
- No claim suggests every track is available, licensed for public performance, or guaranteed to play.
- No personal information, local file names, tokens, or API keys appear in the recording.
- Keep the video private until the owner approves a public announcement.
